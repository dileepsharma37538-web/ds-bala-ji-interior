DS BALA JI INTERIOR — SERVICES + PROJECTS + GALLERY UPDATE
============================================================

WHAT WAS ADDED
1. Manager Portal -> Services & Projects
   - Furniture & Woodwork
   - Civil Work
   - Painting & Finishing
   - Interior Solutions
   Manager can add a project inside the correct service, with name, description, multiple photos and videos.

2. Manager Portal -> Gallery
   Manager can separately add general photos/videos with title and description.

3. Public website
   - Clicking a service card opens that service's projects.
   - Manager-added project photos/videos appear inside that service.
   - Manager-added Gallery media appears in the public Gallery.
   - Customers do not need a login.

4. Existing features retained
   Workers, Attendance, Payments, Manager Private Data and Firebase login remain.

FIREBASE
--------
The supplied manager.js already contains the Firebase Web App config previously provided for the DS BALA JI INTERIOR project.

IMPORTANT: ENABLE FIREBASE STORAGE
1. Open Firebase Console: https://console.firebase.google.com/
2. Open project: ds-bala-ji-interior
3. Open Build -> Storage.
4. Create/enable the Storage bucket.
5. If Firebase asks you to select a location, choose the location appropriate for your project (Mumbai/India region if offered and suitable).
6. Open Storage -> Rules and paste storage.rules from this package.
7. Publish the rules.

FIRESTORE RULES
---------------
Open Firestore -> Rules and replace the rules with firestore.rules from this package, then Publish.

The rules make project/gallery documents publicly readable so the customer website can display them. Writes still require Firebase Authentication.

SECURITY NOTE
-------------
For production, the best setup is to replace `request.auth != null` on write rules with the exact Firebase manager UID. This ensures only the manager account can upload/edit/delete.

HOW MANAGER ADDS A SERVICE PROJECT
----------------------------------
Manager Login -> Services & Projects -> choose the service -> + Add Project.
Enter project name and description, choose multiple photos/videos, then Save Project.

HOW MANAGER ADDS GENERAL GALLERY MEDIA
---------------------------------------
Manager Login -> Gallery -> Add Gallery Media -> title/description -> choose photos/videos -> Save to Gallery.

MEDIA STORAGE
-------------
Photos/videos are stored in Firebase Storage. Firestore stores the project/gallery information and media URLs.
